## 🎮 مراحل بازی

1. **مرحله ۱ — رمزگشایی باینری (Binary Decoder):**
   - نمایش عدد ده‌دهی رندوم بین ۰ تا ۲۵۵
   - کلیدهای ۸ بیتی برای ساخت معادل باینری عدد در زمان ۳۰ ثانیه

2. **مرحله ۲ — حافظه بیتی (Bit Memory):**
   - شبکه ۴×۴ کارت‌های مخفی با آیکون‌های بانکی/تکنولوژی
   - جفت کردن کارت‌های مشابه با زمان ۶۰ ثانیه

3. **مرحله ۳ — رمز ۲۵۶ (Code 256):**
   - بانک سوالات تخصصی کامپیوتر، باینری، شبکه و منطق ریاضی
   - بدون سوال تکراری با زمان ۴۵ ثانیه

4. **مرحله ۴ — شکار بیت (Bit Hunter):**
   - بارش بیت‌ها با سرعت‌های مختلف و اعداد ۲، ۳ و ۴
   - پرسش و تغییر رندوم هدف در هر دست برای جلوگیری از حفظ کردن
   - زمان ۳۰ ثانیه
